# Versiones del Sistema (APPSET)

El parámetro `APPSET` define la versión del sistema ContaPortable que se está ejecutando. Este parámetro se utiliza internamente para habilitar o deshabilitar módulos, reportes y funcionalidades específicas.

A continuación, se detalla el listado de valores válidos para el parámetro `APPSET` y su respectiva versión comercial:

| APPSET | Nombre de la Versión |
|--------|------------------------|
| **CONTAP** | Contaportable Avanzado |
| **CONTA3** | Contaportable Plus |
| **CONTA** | Contaportable Básico Contabilidad |
| **IVA** | Contaportable Básico IVA |
| **RENTA** | Contaportable Básico Renta |
| **PLANILLA** | Contaportable Básico Planilla |
| **INVFACT** | Inventario y Facturación |
| **INVENTARIO** | Inventario |
| **FACTURA** | Facturación |
| **FACT** | Facturación |
| **INVFACT2** | Contaportable Pro |
| **DONACIONES** | Contaportable Donaciones |
| **PYMEPRO** | PymePro |
