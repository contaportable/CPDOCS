# Parámetros Generales en contaportable

## ⚙️ Configuración

!!! example "Listado de parámetros generales"
    ??? note "GRIDCNCTASICOS"
        | Campo | Detalle |
        | ----- | ------- |
        | **Valor Default** | `SI` |
        | **Valores posibles** | `SI` / `NO` |

        **Descripción:** Para instalaciones en SO Windows 7 y Windows 8 en los cuales algunos iconos recientes no son compatibles, al abrir los formularios de cuentas contables y clientes, se puede establecer el valor del parámetro en **NO** y se visualizarán iconos genéricos, permitiendo abrir los formularios sin problemas.

        **GRIDCNCTASICOS="SI" por default**
        ![GRIDCNCTASICOS activado — iconos originales](../../assets/ParametrosGenerales/GRIDCNCTASICOS_TRUE.png){ align=center }

        **GRIDCNCTASICOS="NO" mostrara iconos genericos**
        ![GRIDCNCTASICOS desactivado — iconos genéricos](../../assets/ParametrosGenerales/GRIDCNCTASICOS_FALSE.png){ align=center }
