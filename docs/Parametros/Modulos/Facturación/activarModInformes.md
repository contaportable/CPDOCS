# Parámetro — Activar Módulo de Informes en sistemas de facturación

Ahora CP permite instalar el módulo de informes en sistemas de facturación electrónica y electrónica con inventario, dicha opción no esta incluidada en versiones estándar o clasicas, por lo que nos reservamos el derecho de instalar unicamente a clientes que adquieran esta función, para mayor información consulte con el área de ventas.
