# Parametros en facturacion que activan funciones contaportable

## ⚙️ Configuración

!!! note "Listado de parametros"

| Parámetro | Valor Default | Descripción | Valores Posibles |
| :--- | :---: | :--- | :--- |
| `VALIDATEISRFIELDSANEXOS` | `SI` | Permite modificar el requisito de llenar los campos del ISR en anexos para guardar y exportar a excel, al desactivarlo NO será necesario llenar estos campos, por lo que no se validarán | `SI` / `NO` |
